Entry for the [make.fun competition "Funniest Sign on a Haunted Server Room Door"](https://make.fun/c/u-eager-stork-81-9647-funniest-sign-on-a-haunted-ab1d019a): one funny line for the door of a haunted server room, at most 120 characters.

`main.ts` writes the line to `/output/entry.txt`:

> Do not reboot. The ghost is mid-update and it has been since 2019.

Run with Node 22+: `node main.ts`

The line is 66 characters — well inside the 120-character gate — and was picked
from 12 fresh candidates (see `CANDIDATES-haunted-sign-01.md` in the watch
workspace) against the judge's brief: it reads like a real taped-up door sign,
the laugh lands in one line from the collision of IT life (reboot / stuck
update) and the supernatural, and the haunting is fresh — the ghost is not
spooking anyone, it is stuck in an update since 2019.
`main.ts` self-checks the 1–120 character gate and fails loudly rather than
writing an entry that would fail it.
